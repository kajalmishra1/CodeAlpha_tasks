# 🚀 CodeAlpha Tasks

This repository contains the tasks completed as part of my **CodeAlpha Internship**. Each task is organized into its own folder with complete source code and documentation.

---

## 📂 Tasks Completed

### ✅ Task 1: UniVoice — Multilingual Translation Web App
📁 [`Task-1-UniVoice-Language-Translator`](./Task-1-UniVoice-Language-Translator)

A full-stack real-time translation web app supporting 70+ languages, with voice input, text-to-speech, auto language detection, translation history, and a glassmorphism UI with dark/light mode.

**Tech Stack:** React, Vite, Tailwind CSS, Node.js, Express, Deep Translate API
🔗 Live Demo: [uni-voice-five.vercel.app](https://uni-voice-five.vercel.app)

---

### ✅ Task 2: AI Food Delivery Chatbot
📁 [`Task-2-AI-Food-Delivery-Chatbot`](./Task-2-AI-Food-Delivery-Chatbot)

An AI-powered chatbot built to assist users with food ordering and delivery queries through natural conversation, using NLP-based intent matching.

**Tech Stack:**
| Layer | Technology |
|---|---|
| NLP Engine | Python, scikit-learn (TF-IDF + Cosine Similarity) |
| Backend | Flask |
| Frontend | HTML, CSS, JavaScript |
| Fonts | Cormorant Garamond + Karla (Google Fonts) |
| Dataset | Custom `intents.json` (20 intents, 400+ patterns) |
